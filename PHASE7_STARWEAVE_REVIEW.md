## Production behaviour

**Games → Starweave** lazily loads `musicbox.js`, then the production model, transport and view. The accepted musical spell circle is retained: sixteen clockwise moments per circle, four initially C4/E4/G4/C5 pitch rings, Star chime/Ember pluck/Moon hum, explicit 1/2/4-moment durations, visible spell connections and the actual production animated pet rig. Its SVG definitions, classes, variables and animation names are scoped privately so it does not interfere with the desktop pet. Pet counts/location/personality remain independent.

Place/replace/erase, Undo, deliberately enabled sound, Cast/Stop, tempo and loop all remain. Large numbered controls provide the same placement and erasure as the circle. Left/Right crosses circle boundaries; Up/Down selects a pitch; Enter/Space uses the native button; Delete/Backspace erases. There is one roving Tab stop among the sixteen moment controls, with full note/hold labels. Short/narrow windows scroll rather than shrink their controls out of legibility. Selection, sounding moment, hold labels and written playback position remain visible without animation.

One to eight circles provide 16–128 moments. The star and displayed circle follow the audio clock through the whole piece. Holds may overlap another attack and cross a circle boundary; they must end inside the composition. Removing a nonempty last circle or a continuing hold is refused with feedback, rather than dropping notes. Tempo is 50–160 BPM, four moments per beat. Dragging tempo stops playback immediately; releasing commits one undoable edit.

Six major/minor/pentatonic presets and four editable pitch-ring selectors supply predictable choices from C3–C6. Every event has an independent MIDI pitch, absolute zero-based start, explicit duration and stable ID. Replacing a rune retains the ID. Palette changes never retune notes. Kept pitches outside the palette appear on dashed edge sockets with pitch text and equivalent numbered-control descriptions.

The accepted three original remix recipes preserve their exact preview pitch/voice/start/duration data. Three additional original four-note activities use the same model and synthesis. Match the tune checks exact rune, pitch, start, duration and composition length, ignores generated IDs/title/tempo/loop, rejects extra attacks and reports matches/unmatched notes. A complete written hint avoids making hearing or timed responses necessary. Practice retains the original composition/circle/cursor/history and never overwrites its autosave or named library. Check/Return stop playback; Return restores the original spell and moves focus to the activity's start control.

## Persistence and exports

Version 1 storage uses `kasai:starweave:v1`, with a validated autosave, up to 24 named independent snapshots and a persisted last-deletion recovery slot. New saves, explicit selected replacement, load, delete and Undo last deletion use labelled native controls. Title can be committed explicitly with Set title or on leaving its field. Valid imports, loading recipes/patterns, Clear and New participate in the sixty-snapshot open-window Undo history. Autosaved compositions, named entries and deletion recovery survive reload; Undo history and practice answers do not.

Invalid/unsupported stored data stays untouched. Valid entries in a damaged library remain readable while writes are blocked. Quota/blocked-storage failures clearly retain the open spell in memory and offer JSON backup. Another tab changing the library blocks overwriting it. Recovery can download the exact raw library and requires a distinct confirmation before starting fresh, retaining the open composition. No historical rectangular-grid save format is silently migrated.

Editable JSON exports/imports preserve all explicit music and IDs. Strict validation rejects unknown fields/versions, malformed JSON, duplicate starts/IDs, unsupported runes/pitches, bad durations and out-of-bounds notes. File size/text limits apply before import. Files are staged in the editor before Apply JSON; stale reads cannot overwrite a later file selection or composition edit. Invalid imports leave the composition unchanged. PNG export snapshots every circle with connections, exact pitch/duration text keys and cross-circle holds. An early crowded edge-label export was revised to put readable note keys under each circle. MIDI/audio export remains outside scope.

Exact storage schema, editable example, limits and authoring locations are in [STARWEAVE_AUTHORING.md](STARWEAVE_AUTHORING.md). All built-in music is agent-created original material, not attributed to Andrew. Existing art/writing author content was not fabricated or replaced.

## Sound and OS lifecycle

The production transport retains the accepted chime/pluck/hum harmonics and envelopes. It feeds the existing `sound.js` compressor/master and global mute preference through a deliberately acquired instrument channel. It schedules a short 150ms horizon against AudioContext time, not animation time. Every harmonic and queued attack is owned and disconnected on cancellation; long notes are scheduled for their actual duration. A clock stall stops instead of replaying a backlog.

Stop, editing music/title/JSON, tempo/loop changes, mute, global hush, document hiding, browser blur/pagehide, another OS window taking focus, focus moving outside the app, minimisation, close and AudioContext suspension/interruption cancel playback. No automatic music resumes on return. Async resume uses a generation token: a cancelled activation cannot start later, and an obsolete request cannot stop its successor. Cleanup removes event subscriptions, DOM listeners, audio-state listeners, the transport interval, animation frame and object URLs. The existing event hub now returns an unsubscribe function; OS stacking emits active-window changes. Other apps retain the same hub API.

Browser review found a close/reopen race in deferred cleanup. The loader now unmounts synchronously before the OS replaces the body, and disposed views cannot repaint it. Another review found that an empty pet `data-frame` attribute also freezes the rig: normal motion now removes that attribute, while reduced motion sets an explicit still. Both have regressions. An explicit Set title control also makes title commitment clear before exporting.

The build syntax-checks ES modules without executing them and stamps transitive module dependencies before parent lazy-loader/HTML hashes. A regression changes a leaf model and confirms its cache version propagates through the complete chain. Review sources remain under `tests/`; no production debug API or preview dependency was added.
